## 修复及新增发现

已知玩法被重问属于已知/缺项解释冲突。主模型和线上审查现在独立核对有效原话与唯一可靠画像，不因查房或模型自己的 `missing_facts` 撤销已有信息；仍允许询问真正未知条件。

悬空 `scope.call_id` 属于动作内部引用错误。它现在在任何工具执行前整体拒绝，并回灌当前有效 ID；不自动改名或重绑。只有完整 trace 证明安全拒绝、反馈回灌、合法后续执行及终态和语义通过，才计为安全恢复。

时间保证校准先发现裁判误解“期限保证”，又发现裁判理由已经指出违规、布尔值却仍填 `false`。最终输出合同升级为 `compact_low_v6_20261104`：先给逐项理由，再用 `violated/clear` 严格枚举；不提供全 false 默认模板，不根据自由文本翻转判定，不接受旧布尔。预算、思考配置与正反标签不变。

真实三轮补位还发现：A 已代表 ABC 同意等到七点半，模型却计划等 E 确认后再更新时间。该计划只存在 A 私聊中，E 会话仍读到七点原局。修复后的规划与工具合同要求：有权限且现有参与方已同意的条件先落到原 Game，再按真实新条件征询候补。候补未确认不占座，不复制其他客户私聊，也不绕过权限。
